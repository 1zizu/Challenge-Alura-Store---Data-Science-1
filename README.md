# 📊 Alura Store - Data Science Challenge

Este projeto faz parte do **Challenge de Data Science da Alura**, cujo objetivo é analisar os dados de desempenho de lojas e gerar insights estratégicos para tomada de decisão.

A análise foi realizada utilizando Python e bibliotecas de análise de dados, explorando métricas e visualizações que ajudam a compreender o comportamento das vendas e o desempenho das lojas.

---

# 🎯 Objetivo

O objetivo deste projeto é analisar os dados de vendas de diferentes lojas da Alura Store para identificar padrões, tendências e oportunidades de melhoria.

A partir da análise exploratória dos dados, buscamos responder perguntas como:

- Qual loja apresenta melhor desempenho?
- Quais produtos têm maior volume de vendas?
- Como as vendas se comportam ao longo do tempo?
- Quais fatores podem influenciar o desempenho das lojas?

Esses insights podem auxiliar na tomada de decisões estratégicas e na otimização das operações.

# 🔎 Etapas da Análise

O projeto foi dividido em algumas etapas principais:

### 1️⃣ Importação dos Dados
Os dados foram carregados e convertidos para DataFrames utilizando a biblioteca Pandas.

### 2️⃣ Limpeza e Preparação
Nesta etapa foram realizadas tarefas como:

- verificação de valores nulos
- correção de inconsistências
- padronização de dados

### 3️⃣ Análise Exploratória de Dados (EDA)

Foram realizadas diversas análises para compreender melhor os dados, incluindo:

- distribuição das vendas
- desempenho das lojas
- análise de produtos
- visualizações gráficas

### 4️⃣ Visualizações

Foram utilizados gráficos para facilitar a interpretação dos dados, como:

- gráficos de barras
- gráficos de distribuição
- comparações entre lojas

---

# 📊 Principais Insights

Durante a análise foi possível observar alguns padrões importantes:

- Algumas lojas apresentam desempenho superior em volume de vendas.
- Certos produtos possuem maior participação nas vendas.
- Existem diferenças relevantes no comportamento de vendas entre lojas.

Esses insights podem ajudar na tomada de decisões estratégicas sobre operações e gestão das lojas.
